# Velis Auto Brightness

Velis Auto Brightness is an Android app that adjusts screen brightness automatically, based on how much light
reaches the screen. It reads the light sensor and, optionally, the front or back camera, maps the reading onto a
brightness curve you control, and applies the result. Every point of that curve can be inspected and reshaped, so
brightness stays where you need it at any light level, which matters for light sensitivity such as migraines,
photophobia or low vision.

The app is free, including switching profiles from Tasker. The other Tasker/Locale plugin settings and all of
its conditions, and the home-screen widget's profile button, statistics and transparent background, are part of
the paid Tasker/widget add-on in the app's **In-app store**.
